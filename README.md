# nova-sync-packages

Sync packages for the **Nova Sync** Figma plugin (RegScale/rs-ui `figma-sync.yml`).

- `latest/package.json` — the package the plugin fetches (moves only on a `main` run that descends from the package it replaces).
- `packages/<sha7>/package.json` — every published package, immutable.
- Releases `sync-<sha7>` and `latest` carry the same JSON as assets.

Everything here is generated by CI from `libs/ui` design tokens; nothing is edited by hand. Contents are public design-token data (no credentials).
